# Proyecto Integrador (Login) - Fase 1

Este proyecto corresponde a la primera entrega del sistema de gestión de notas y asistencia.

## Contenido
- `index.html`: Página principal de inicio de sesión.
- `css/estilos.css`: Estilos básicos de la interfaz.
- `js/login.js`: Lógica de validación de credenciales con funciones, condicionales y ciclos.

## Instrucciones
1. Clonar el repositorio.
2. Abrir `index.html` en un navegador.
3. Usuario: `admin` | Contraseña: `1234`
4. Máximo 3 intentos antes de bloqueo.
